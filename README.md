# PerlOps Engineering

Official engineering standards, architecture guidelines, development practices, and reusable templates for the PerlOps ecosystem.

## Purpose

This repository establishes a consistent engineering framework for building secure, reliable, maintainable, and extensible software across PerlOps projects.

## Engineering Principles

- Security by design
- Automation first
- Modular architecture
- API-first integration where appropriate
- Cloud-agnostic design
- Responsible AI integration
- Observability by design
- Reproducible development environments
- Continuous testing and validation
- Clear technical documentation

## Technology Standards

| Area | Standard |
|---|---|
| Primary language | Perl 5 |
| Initial minimum Perl version | 5.36 |
| Dependency management | CPAN, cpanfile, cpanminus |
| Code formatting | Perl::Tidy |
| Static analysis | Perl::Critic |
| Testing | Test2::V0 |
| Code coverage | Devel::Cover |
| Documentation | POD and Markdown |
| CI/CD | GitHub Actions |
| Containerization | Docker |
| Versioning | Semantic Versioning |
| Commit convention | Conventional Commits |
| Software license | Apache License 2.0 |
